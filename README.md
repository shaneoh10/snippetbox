# Snippetbox

Snippetbox is a web application built with Go that allows users to create, store, and share snippets of text.

This project is being developed by following [Let's Go](https://lets-go.alexedwards.net/) by Alex Edwards, a book that teaches how to build a web application from scratch using Go.

The project serves as a practical way to learn the fundamentals of building web applications with Go.
